# Pruebas integrales

Aquí vivirán pruebas de contrato y del flujo menú → pedido → lealtad, además de verificaciones de salud, métricas y persistencia.

La primera capa verificará los archivos de [`docs/openapi/`](../docs/openapi/README.md). Después se comprobará que las respuestas reales respetan esquemas, códigos HTTP, tipos de contenido e idempotencia.
